# list 修改时间距今显示

## 目的

当前 `doco list` 只显示状态、变更 ID 和任务进度，无法直接判断哪个变更最近有活动。为列表增加“距上次修改时间”，使用紧凑的整数单位，让终端和脚本无需解析带小数的时长。

## 范围与完成标准

- `list` 为每个变更计算工作包根目录及全部后代中最新的文件系统修改时间，并显示它距本次列表查询时刻的时长。
- TTY 宽表增加 `UPDATED` 列；窄表在每行末尾追加时长；重定向输出追加第四个 TSV 字段，前三列顺序和含义不变。
- 时长不带小数：不足一小时显示整分钟（如 `10m`），不足一天显示整小时（如 `20h`），一天及以上显示整天和非零剩余整小时（如 `1d2h`、`20d5h`，整天时为 `1d`）。不足一分钟或未来时间显示 `0m`。
- 读取修改时间沿用项目文件安全检查；遍历或元数据读取失败应使 `list` 明确失败，不能返回误导时间。平台无法提供任何修改时间时显示 `?`。
- `doco list` 默认只查询并显示 active；`doco list --completed` 追加 completed，`doco list --archived` 追加 archived，两项可组合以显示三种状态。未选中的状态不得因其任务文件或工作包读取错误导致命令失败。
- 增加格式边界、TTY/管道布局、状态过滤及现有列表行为的回归测试，并同步 CLI 契约和架构说明。

非目标：不持久化时间戳、不改变 ID 排序、生命周期状态、任务计数、安全锁或文档格式，不增加排除 active 或仅显示历史状态的模式，不承诺秒级精度。
