# 分层任务编号

## Purpose

当前任务格式使用 `T` 加三位以上数字，无法直接表达任务所属阶段。项目今后统一使用 `1.1`、`1.2`、`2.1` 形式的两级数字编号，使任务分组和依赖关系更易阅读。

## Scope and acceptance

任务行和依赖项的唯一合法 ID 改为两个以点分隔的正整数；每段不得为零或带前导零，例如 `1.1`、`1.2`、`2.1`。检查器拒绝原 `T` 加数字格式，不提供兼容或自动迁移。唯一性、依赖存在性、无环和完成状态约束保持不变，不额外要求编号连续或按文档顺序递增。

源码、测试、当前格式文档、发布与安装态 skill 模板及引用，以及仓库内 active/completed 工作包中的旧编号全部迁移；代码围栏和注释仍不计为任务。除任务 ID 语法外，不改变任务计数、生命周期、归档或 Markdown 字段契约。

## Result

已将任务和依赖 ID 切换为 `1.1`、`1.2`、`2.1` 形式的两级正整数编号，旧格式不再接受。解析器、测试、格式文档、两份 skill、模板及仓库 active/completed 工作包均已迁移，完整质量检查通过。
